# Responsive Image Gallery with Lightbox & Filters

## Project Description
This is a responsive image gallery built using HTML, CSS, and JavaScript. 
It features hover effects, category filters (Nature, Animals, Travel), and a lightbox view with next/prev navigation for easy browsing. 
The design adapts to all screen sizes for a smooth user experience.

## Features
- Responsive grid layout using CSS Grid
- Hover effects with smooth transitions
- Lightbox view with Next/Prev and Close buttons
- Category filters (All, Nature, Animals, Travel)
- Works on desktop, tablet, and mobile devices

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## How to Run
1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Click on images to open the lightbox and use filters to view categories.
